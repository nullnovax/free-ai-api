# Contributing

Contributions are welcome.

## What to Add

Useful contributions include:

- Verified free AI API services
- Signup promotions and trials
- AI API gateways
- Claude, GPT, Gemini, Codex and other model access
- Developer documentation
- Corrections to outdated information

## Submission Guidelines

Before adding a service:

1. Verify that the service is currently available.
2. Verify signup or promotional claims before publishing them.
3. Do not invent pricing, credits, model availability, or limits.
4. Keep descriptions short and factual.
5. Clearly disclose referral links when they are used.

## Quality Standard

Information can change quickly. If a service changes its pricing, models, limits, signup promotion, or availability, update the documentation or open a pull request.

## Referral Links

Referral links must be clearly disclosed and should only be used when they are relevant to the documented service.
